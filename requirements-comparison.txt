# Dependencies for the OPTIONAL Experiment 8 pipeline comparison
# (InsightFace SCRFD detection + ArcFace buffalo_l recognition).
#
# Deliberately kept out of requirements.txt. The five baseline experiments, the
# BFW open-set experiment, the review classifier and the whole test suite run
# without anything below.
#
# LICENSING. InsightFace publishes its pretrained models for non-commercial
# research use, and this artefact is non-commercial MSc academic research, so
# that use is within those terms. The models are created and trained by the
# InsightFace project; nothing here trains or fine-tunes them, no weight file is
# redistributed or committed, and no ownership is claimed. The MIT licence
# covering InsightFace source code does not automatically extend to the weights.
#
# --------------------------------------------------------------------------
# INSTALLATION - do not use a plain "pip install -r" on this file.
# --------------------------------------------------------------------------
#
# insightface declares a dependency on opencv-python. Installing it normally
# pulls that distribution in alongside opencv-python-headless. Both ship the
# same cv2 module, so whichever wins the import shadows the other. That
# silently changed YuNet detection and SFace embedding numerics, moved the
# frozen classifier threshold, and still passed the dependency contract,
# because package metadata continued to report the pinned headless version.
#
# A constraints file does NOT prevent this: constraints bound the version of a
# package that is installed, they do not stop a different distribution being
# resolved. Install with --no-deps and supply the dependencies explicitly:
#
#   python -m pip install --no-deps insightface==1.0.1
#   python -m pip install \
#       onnxruntime==1.28.0 \
#       opencv-python-headless==4.13.0.92 \
#       numpy==2.5.1 \
#       scikit-image scipy onnx tqdm easydict prettytable requests
#
# pip warns that "insightface requires opencv-python, which is not installed".
# That warning is expected and correct to ignore: the headless distribution
# provides the same cv2 module, and this is the only way to keep exactly one
# effective OpenCV in the environment.
#
# Verify before running any evaluation:
#
#   python -c "import cv2; print(cv2.__version__)"    # must print 4.13.0
#
# check_dependency_contract() also verifies the imported cv2 version at runtime
# and refuses a reportable evaluation when another OpenCV shadows it.
#
# Verified from a clean virtual environment: opencv-python absent,
# opencv-python-headless 4.13.0.92 effective, insightface.model_zoo and
# insightface.utils.face_align both importable.

insightface==1.0.1
onnxruntime==1.28.0
